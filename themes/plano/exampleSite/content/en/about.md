---

This is the example site that ships with the Plano theme. It exists so the
theme can be built and looked at on its own, without borrowing anything from
the blog it came from.

- Two languages, English at `/` and Spanish at `/es/`.
- Three entries per language, with tags, a table of contents and a code block.
- Client-side search reading a JSON index generated by Hugo.
- Light by default, with the dark variant one click away.

Delete this folder and write your own site; the theme does not read anything
from here.
